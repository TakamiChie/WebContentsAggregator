# Discord Webhook 通知

プロジェクト直下の `setting.json` に `DISCORD_WEBHOOK_URL` を設定します。既存の `settings.json` に同じキーを追加する方法も使えます。

```json
{
  "DISCORD_WEBHOOK_URL": "https://discord.com/api/webhooks/WEBHOOK_ID/WEBHOOK_TOKEN"
}
```

両方のファイルにキーがある場合、通知には `setting.json` の値を使います。`--settings` で設定ファイルを指定できるスクリプトでは、指定ファイルの値を使います。通知を停止するには値を空文字にします。通知には PHP の `curl` 拡張が必要です。Webhook URL には投稿用のトークンが含まれるため、設定ファイルは Git の追跡対象外です。

- 📥 収集開始と取得結果。SQLite のコミット後に、取得件数、実際に追加・更新した件数、変更した記事のタイトルを通知します。
- 📝 記事ごとの概要生成結果。記事タイトル、概要本文、タグ、ハッシュタグを通知します。`--nodb` の場合はプレビューとして投稿します。
- 📤 トピック分類、SQL 出力、SQLite 転送、Notion 同期の進捗と結果を通知します。
- ⚠️ 取得できなかったフィード、処理の失敗、スキップ件数などを通知します。エラーの詳細は各スクリプトの実行ログで確認できます。

長文は Discord の投稿上限に合わせて分割します。Webhook の送信に失敗した場合は標準エラーに警告を出し、その PHP プロセスの本処理は続行します。
