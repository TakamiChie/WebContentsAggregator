## 分布から分かること

異なるタグの約70%が1記事にしか現れません。自由生成タグには固有名詞、一般的なテーマ、細かい表現が混在しています。サイト側のタグ名への完全一致だけでは対応できない記事が多く、別名・内容タグの対応表が必要です。分布のみで「対応できない記事＝サイトの活動と無関係」と断定できません。

候補は採用していません。固有名詞の別表記と、一般的な話題の対応条件は個別に確認が必要です。例えば「緑園学園」だけではプログラミング講座への言及とは限らず、「横須賀支部」だけでは団体を特定できません。また、「大和縁乃庭」「山田縁乃庭」などのタグも存在しますが、誤認識か別の活動かはタグだけでは判断できません。類似文字列を自動でまとめる処理は行っていません。

全タグの出現件数、全21トピックの共起とlift、未生成記事IDは [topic-tag-distribution.json](topic-tag-distribution.json) に収録しています。共起候補は対応条件を検討する資料であり、自動確定の根拠にはしていません。

## 再集計と分類

```powershell
php classify_topics.php --analyze --top 11000 | Set-Content -Encoding utf8 out/topic-tag-distribution.json
php classify_topics.php --nodb
```

対応表を `topic_classifier.aliases` / `tags_any` / `tags_all` / `tags_none` に設定した後は、`php classify_topics.php --force` で `llm_hashtags` のみを再生成できます。AIは呼び出しません。今回実行したのは読み取り専用の分布解析だけです。
